# 美佳のタイプトレーナー Web (統合拡張版)

名作タイピング練習ソフト「美佳のタイプトレーナー」JavaScript版の完全統合＆高機能拡張版です。

---

## 🌟 主な機能と特徴

### 1. メニュー構成 (数字キー 1〜9 対応)
- **1. ポジション練習**: ホームポジション、上一段、下一段、数字、全段
- **2. ランダム練習**: 60秒タイマー、リアルタイム打鍵速度(文字/分)計算
- **3. 英単語練習**: 基本英単語、MS-DOSコマンド、C言語、Pascal、Fortran、BASIC、8086アセンブラ
- **4. ローマ字練習**: 基本ローマ字、ローマ字単語(完全版辞書データ収録)
- **5. 成績表示**: 達成日・タイプ速度・累積練習時間
- **6. 分析・弱点データ (Analytics)**:
  - **苦手キーの自動追跡とヒートマップ表示**: キーボードレイアウト上にミス頻度をグラデーション表示（青:得意 → 緑 → 黄 → 橙 → 赤:苦手）
  - **指ごとのパフォーマンス集計**: 左手小指〜右手小指の担当指ごとに累計打鍵数とミス率を算出
  - **成長トレンド折れ線グラフ**: 過去の練習CPMの推移をCanvas上にレトロな折れ線グラフで描画
- **7. 対戦モード (オフライン・オンライン)**:
  - **オフライン練習**: ゴースト対戦
  - **オンライン対戦**: ルーム作成・参加（自由なルームコード、公開/非公開設定、単元ジャンル選択、チート使用可否ルール設定）
  - BroadcastChannel APIによるサーバー不要・即時リアルタイム対戦（ブラウザの別タブ同士で同期）
- **8. 実績 (アチーブメント)**: 条件達成でポップアップ通知＆LocalStorage永続保存
- **9. 裏メニュー (美佳のタイプトレーナー枠内に統合)**:
  - チート・おふざけモード設定、速度倍率、自動打鍵速度、サウンド設定

### 2. キーボードショートカット
- **F2**: 自動入力モードの ON / OFF 切替
- **F3**: 空白記号の可視化切替（「␣」⇔ 通常の半角スペース）
- **F4**: 速度倍率の切替（1.0倍 ⇔ 10.0倍 ⇔ 100.0倍）
- **F5**: 🎆 **ドパガキモード**（ネオン＆レインボー背景、文字飛び散り、脳汁スコア表示）
- **F6**: 🤖 **完全オートパイロット**（ミスゼロ・超高速自動クリア）
- **F7**: 🛡️ **無敵イージーモード**（どのキーを押してもミスにならず正解進行）
- **ESC**: 中断 / 一つ前のメニューに戻る
- **Enter**: 決定 / 練習終了時のリトライ

### 3. 表示機能
- **ライトモード / ダークモード切替** (画面右上)
- **中心メイン枠のみ全画面表示** (枠右上)
- **「キー補助すら非表示 (純粋枠)」**: 全画面時に下部ボタンすら隠し、純粋なCanvas枠のみに集中可能

## 🚀 GitHub Pages への公開方法

本リポジトリには `.github/workflows/deploy.yml`（自動デプロイ設定）が同梱されています。

1. GitHubにリポジトリをPushします。
2. リポジトリの **Settings** > **Pages** に移動します。
3. **Build and deployment** の Source を **GitHub Actions** に設定します。
4. 自動的にビルド・デプロイが完了し、公開URLで404やMIMEエラーなしで動作します。

> **※ 手動でアップロードする場合**:  
> `npm run build` を実行して生成される `dist` フォルダ内のファイル一式を公開サーバーに配置してください。

## 💻 ローカル環境での実行方法

ブラウザのセキュリティ制限(CORS)により、HTMLファイルを直接ダブルクリック (`file://`) して開くことはできません。

```bash
# 1. 依存関係のインストール
npm install

# 2. 開発サーバーの起動 (http://localhost:3000)
npm run dev

# またはビルド済みのプレビュー
npm run build
npm run preview
```
